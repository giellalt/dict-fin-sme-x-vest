# Dictionary for fin — sme

This repository contains source files for Jouni Anti Vest's dictionary from Finnish to North Sámi. The content is licensed under the CC-BY-4.0 license.

Many of the dictionaries are published on [sátni.org](https://sátni.org) and [NDS](https://sanit.oahpa.no).

# Directory structure

The directory is structured as follows:
```
conv/ - Source files converted to other formats for further use
  jav_finsme.html - HTML version
  jav_finsme-for-xmlconvert.html - HTML version stripped of non-dictionary content
  jav_finsme.xml - HTML converted to GT XML, but not modified further
docs/
export/
  fin-sme.xml - an edited version of jav_finsme.xml for export to other dictionaries. Spelling corrected, POS added.
inc/ - Original source files from JAV
```
